# First-Person Mod for The Walking Dead

Step into Lee's viewpoint. An experimental mod for **The Walking Dead: Season One, original Windows Steam edition, episodes 1–5**.

Includes cutscene free-look, focus assistance, optional exploration weapons, camera smoothing, recovery and diagnostic logs. Stations, close-ups, QTEs and scripted combat preserve the game's required viewpoints and controls.

**Compatibility:** original 2012 Season One. Definitive Series and later seasons are unsupported.

## Install

1. [Download the v0.5.1 prerelease](https://github.com/tudorek12345/first-person-mod-for-the-walking-dead-game/releases/tag/v0.5.1) and extract the ZIP.
2. Close the game, then double-click **Install.cmd**. Steam libraries are detected automatically; enter the game folder if prompted.
3. Launch through Steam.

No Python required. Internet is needed once. If Windows denies access, right-click **Install.cmd** and choose **Run as administrator**. To remove the mod, close the game and run **Uninstall.cmd**. Logs and backups are under `%LOCALAPPDATA%\First-person-mode`.

## Controls

| Key | Action |
| --- | --- |
| F6 / F8 | Toggle first person / retry recovery |
| Mouse / WASD | Look / original movement and cover actions |
| Right mouse | Aim; look where the scene allows |
| Tab / Alt | Refocus / hold for original interaction framing |
| G / 1–3 | Draw weapon / select pistol, shotgun or rifle |
| Left mouse / R | Fire / reload during exploration |
| F | Use the focused interaction |

**Experimental:** full campaign progression is unverified. Story-locked free walking, bespoke first-person arms and universal scripted enemy handling are unfinished. Weapon availability varies by episode. [Report issues](https://github.com/tudorek12345/first-person-mod-for-the-walking-dead-game/issues) with logs.
